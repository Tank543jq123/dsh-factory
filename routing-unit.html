路由单元 · 伪 3D 设计稿（吉卜力式：黄铜 / 铜绿 / 暖光 / 蒸汽）

一个模块单独看：左进右出，中间是「读意图 → 列候选 → 打分 → 选中 → 放行」的机械过程

这个单元在做什么

  1. 读意图：卡片从左进来，放大镜沿文字逐行扫，读到「装 GitHub 插件」这类关键词。
  2. 列候选：左侧仪表盘亮起三格：技能库（找手册）、工具（bash/web）、MCP（外部接口）。
  3. 打分：每格指针摆动，分数越高指针越靠右；面板下沿有一排小灯对应命中强度。
  4. 选中：道岔臂转向最高分那条轨，其余两轨的灯变暗（未选中的路仍然可见）。
  5. 放行：闸门抬起，卡片滑入选中轨道；旁边的活塞「咔」一下盖章，表示已记录这次选择。

设计原则：看得见输入看得见比较看得见结果

配色调自《天空之城》《哈尔的移动城堡》：黄铜色金属、氧化铜绿、奶油纸、深棕阴影、暖尘光柱、白色蒸汽。
